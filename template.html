    DXF로 변환하면 대부분 열립니다.

    1. 무료 프로그램 ODA File Converter를 설치합니다.
    2. Output version은 ACAD2018, Output file type은 DXF를 고릅니다.
    3. 변환된 .dxf 파일을 이 화면에 다시 끌어다 놓습니다.

    도면 뷰어

    소개

    DWG·DXF 도면을 브라우저에서 여는 무료 뷰어입니다. 도면 파일은 사용자의 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다. 개인과 기업 모두 무료로 사용할 수 있습니다.

    라이선스

    이 프로그램은 자유 소프트웨어입니다. GNU 일반 공중 사용 허가서(GPL) 버전 3의 조건에 따라 재배포하거나 수정할 수 있습니다.

    보증 없음

    이 프로그램은 유용하게 쓰이기를 바라며 배포되지만, 상품성이나 특정 목적 적합성에 대한 묵시적 보증을 포함해 어떠한 보증도 하지 않습니다. 도면 표시와 측정값은 원본과 다를 수 있으니, 제작·검사 같은 중요한 판단은 원본 CAD 프로그램에서 확인하세요.
